# ReachInbox Email Scheduler

A robust email scheduling system built with Node.js, BullMQ, and React.

## Prerequisites
- Node.js v18+
- Docker & Docker Compose
- Git

## Quick Start
1. Clone the repository and navigate to the root.
2. Copy `.env.example` to `.env` and fill in your Ethereal/Google credentials.
3. Start the infrastructure:
   ```bash
   docker-compose up -d
